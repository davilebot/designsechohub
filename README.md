# Echo Hub · Design System v4.2

Material público da identidade visual da Echo Hub para importar no Open Design.

- `DESIGN.md`: regras e tokens para a extração no Open Design.
- `tokens.css`: tokens CSS da identidade visual.
- `assets/`: logos oficiais, símbolo e favicon.

Cole a URL deste repositório no campo **GitHub or website** do Open Design. Também é possível usar o conteúdo de `DESIGN.md` no campo **Paste DESIGN.md**.

Esta edição pública contém apenas as regras visuais, tokens e arquivos de marca. O HTML completo, as capturas dos sites e a documentação operacional continuam no pacote local. Os arquivos de marca pertencem à Echo Hub.
