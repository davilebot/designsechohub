# Echo Hub · Design System v4.2

Material público da identidade visual da Echo Hub para importar no Open Design.

- `DESIGN.md`: regras e tokens em formato de leitura rápida para a extração.
- `design-system.html`: amostras visuais de cores, tipografia, botões, ícones, componentes e movimento.
- `tokens.css`: tokens CSS usados pela amostra.
- `assets/`: logos oficiais, símbolo e favicon.

Cole a URL deste repositório no campo **GitHub or website** do Open Design. Também é possível usar o conteúdo de `DESIGN.md` no campo **Paste DESIGN.md**.

Esta edição pública omite capturas dos sites, nomes de clientes e documentação interna do pacote completo. A prévia HTML carrega Bricolage Grotesque, Inter e JetBrains Mono pelo Google Fonts; os exemplos de ícones Phosphor e Iconoir usam CDN. Os arquivos de marca pertencem à Echo Hub.
